Step 0: Initial LLM Baselines (Before RLHF)

Let's first examine the state of our LLM before the RLHF process. This is called the baseline model. In practice, this is typically an LLM that has gone through some instruction tuning. For the purpose of this activity, though, our baseline model is a very silly one that has been trained to say 'yes' to everything. Notice how its answers diverge from the correct ones.

Examine the Baseline: Notice how unaligned models guess based on loose word associations rather than reliable facts. Consider how this behavior might frustrate human users seeking accurate answers.
📖 Technical Glossary & Explanations
  • Model: A computational system designed to process inputs and generate predictions or responses based on patterns learned from data.
  • Baseline: The initial performance or output of a system before any training, tuning, or alignment is applied.
  • Evaluation Prompts: Standardized test questions used to measure how well a system performs specific tasks.

Steps 3 & 4: Training Reward Models (The Judges)

📖 Technical Glossary & Explanations
  • Reward Model: An automated scoring system or judge trained to evaluate model outputs and assign numerical scores reflecting human preferences.
  • Training Iterations: Repeated cycles where a system updates its internal parameters using feedback from training samples.
  • Weights: Internal numerical parameters that determine how much influence specific features have on the system's final output.
  • Accuracy: The percentage of correct predictions made by a system compared to expected human judge scores.
