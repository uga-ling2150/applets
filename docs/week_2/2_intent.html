Activity: Recognizing Intents

Learning Objectives

  • Analyze how linguistic features (e.g. syntax, word choice) relate to underlying intents.
  • Experiment with variable language (slang, typos, emotional language) to see if the model maintains accuracy
  • Evaluate the confidence score and determine a threshold where a human agent should intervene

Background

When users type in turns in automated dialogue systems, a single intent (e.g., Track Order) can be expressed in infinite ways. The machine must understand that "Is it even on the truck yet?" means "I want a status update for my item."

In this demonstration, you can only type in one turn at a time (i.e. previous context is not available), and receive an intent classification for that turn. You can only choose one of three simulation contexts. Your job is to understand how the system works by experimenting with it, and trying to break it.

The system is currently set up to handle the following intents:
Track Order Cancel Order Refund Update Address Missing Item

Instructions

  1. Type three different variations of a refund request into the app (e.g., indirect and polite, direct and angry...). How do the confidence percentages shift, and why do you think?
  2. Can you write a sentence that a human would clearly understand as a refund request, but makes the AI give a score of less than 30% for the Refund intent? Or the other way around - a human would clearly see it as not a refund request, but the AI does?

Reflection & Discussion Guide

Think about the following questions:
  • What aspects of language were useful for intent recognition? What kinds of language is difficult for the model to understand?
  • What additional information do you think might improve the system's performance?
  • At what degree of confidence do you think it will be helpful for a human agent to automatically be called to intervene?
  • Is there anything that this type of system simply cannot be equipped to handle, no matter how good the classifier? What are the consequences of this type of restriction?
