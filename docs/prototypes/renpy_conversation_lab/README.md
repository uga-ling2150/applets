# LING 2150 Ren'Py Conversation Lab Prototype

This branch contains a Ren'Py familiarization prototype for a short, course-related branching conversation with ARIA, an AI robot guide. It is a separate prototype and is not Applet 3E.

## Accessibility

- Keyboard: Enter/Space to continue; A/B/C for choices.
- Ren'Py self-voicing: V.
- Ren'Py accessibility menu: Shift+A.
- The Web shell includes landmarks, a skip link, keyboard help, visible focus, a named canvas, and status/input labels.
- Axe 4.12.0 automatic result: 0 violations, 0 incomplete checks, 37 passed checks.
- Canvas dialogue and choices still require manual keyboard, self-voicing, zoom, and screen-reader testing.
