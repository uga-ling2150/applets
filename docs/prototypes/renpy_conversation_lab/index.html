About this activity

This is a Ren'Py visual-novel activity. Meet Aria, an AI guide, and choose how she should respond to a student's request for writing help.

Keyboard controls:

  • Press Enter or Space to continue.
  • Press A, B, or C to choose a response.
  • Press V to turn Ren'Py self-voicing on or off.
  • Press Shift+A to open Ren'Py accessibility settings.
  • Use the arrow keys to move through focusable choices when self-voicing is enabled.

The activity does not use a time limit. Ren'Py self-voicing is available for dialogue and choices.

This interactive activity requires a browser with HTML canvas support. Use the Accessibility Help control for a description and keyboard instructions.
