Activity 11A: Style and Persona

Learning Objectives

  • Identify linguistic features that index persona and social relationships.
  • Compare outputs produced from different system prompts while holding the user question constant.

Background

A system prompt can request a style or persona. Particular words, forms of address, hedges, and evaluations can suggest a social identity or relationship. Interpret these features in context; a stylistic cue does not establish a speaker’s real identity.

Instructions

  1. Edit the two system prompts and generate both outputs, or open the offline practice comparison.
  2. Highlight an exact phrase and explain what it suggests about persona or relationship.
  3. Keep a comparison, change one prompt, and generate again. Compare language evidence across runs.
