Activity 11B: Temperature Sampling

Learning Objectives

  • Explain how sampling settings affect word choice.
  • Compare repeated outputs using language evidence.

Background

Language models choose what comes next from a set of possibilities. This activity shows how sampling settings change those possibilities.

First, use a small model that predicts from just the previous word. Then compare repeated outputs from a real language model.

Instructions

  1. Generate a sentence. Keep the default training sentences and click Generate a whole sentence.
  2. Explore one step. Select a generation step, change one setting, and compare the probability bars.
  3. Compare real outputs. Complete part 1 to unlock part 2. Keep the prompt fixed, generate twice per setting, and quote examples of wording differences.

How the probabilities are calculated

Base probability is the bigram count divided by the total count for this context. For temperature T > 0, the new weight is p raised to the power 1/T. Normalize these weights to sum to one. Top-q uses the same cumulative-mass rule as top-p here. Top-k keeps the k highest probabilities; top-p then keeps the smallest prefix whose cumulative probability reaches p, after normalizing the top-k candidates. Finally, normalize the remaining weights again. Temperature zero uses greedy selection. This order describes the teaching simulation; provider implementations may differ. This model samples words; real LLMs usually sample tokens and use longer contexts.
